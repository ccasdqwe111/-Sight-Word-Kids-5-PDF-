什么是 Sight Words？为什么要先学它？

“Sight Words”是指英语儿童读物中出现频率极高、但不符合自然拼读规则的词汇。美国学者爱德华·多尔奇博士基于儿童书籍统计，整理出了220个高频词，并按难度分为五个级别。这些词有多高频？随便翻开一本英文绘本，50%到80%的内容都是这些词。像the、is、are、was、have、come这类词，用拼读规则根本拼不出来，只能靠视觉记忆，“看一眼就认识”。

孩子如果不先认熟这些词，拼读学再好，读一句话也要卡三四次。正确的顺序是：先掌握 Sight Words，再学自然拼读，或者至少同步进行。这样孩子拿起书来，大部分词一看就认识，剩下少数不规则的也能用拼读规则试着拼，阅读体验会顺畅很多。掌握这 220 个词，孩子就能拥有 75% 以上的英文绘本自主阅读能力。

“Sight Word Kids”到底是什么？

Sight Word Kids 是由东西图书（East & West Books）推出、香港洛斯语言教育公司编著的一套专为 3 至 8 岁儿童设计的英语常见词启蒙教材。整套教材共 5 个级别，每个级别分 A、B 两册，共 10 本书，系统覆盖 220 个高频词，采用螺旋式上升结构，难度循序渐进。

教材的内容编排非常贴合低龄儿童的学习特点。每本书按单元推进，一个单元一个主题（如家庭、动物、食物、学校等），每个单元分成三个板块：第一块是卡通组图，用画面把主题抛出来，孩子一看就知道这单元要学什么；第二块是重点 Sight Words，每个词都标了笔顺，孩子可以用手指描着写；第三块是语法小复习加画画，把前面练过的句型用选词填空的方式再过一遍，顺便画点主题相关的东西。

核心亮点：情境图像 + 主题归类 + 科学复习

这套教材最大的特色是把 220 个高频词用常见句型的形式展示，并进行主题归类。比如学"家庭单元"时，既记 father、mother，又练"This is my father."的表达，孩子不仅能记单词，还能掌握句型结构。

教材还设计了阶梯式复习机制：每 3 个单元安排一次小复习，通过"圈单词""填句子"等方式回顾学过的内容；整本书学完后还有一次大复习（Big Review），部分以儿歌形式串联 Sight Words，孩子唱着歌就能巩固，不用死记硬背。
